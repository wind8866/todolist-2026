## 产品背景
### 背景
用户在日常生活中存在任务管理混乱的问题，想要通过软件实现以下需求：
- 想要记录任务
- 想要查看目前有哪些待办任务
- 想要持续跟踪某个任务的进展
### 目标
给用户提供一个能够管理待办任务的软件。该软件是网页应用，可在线访问，但是数据会存在用户本地设备中
 
## 用户画像
### 目标用户
想要使用软件进行计划规划的人
### 核心痛点
无法将心中随时想到的待办事项记录下来进行管理和跟踪处理，导致时常遗漏做某件事
 
## 使用场景
- 用户心中有一个想延后做的待办，使用软件记录下来
- 用户想看哪些今天有哪些任务待处理，哪些任务过期了
- 用户想看已经完成了哪些任务
 
## 产品范围
### 本期（V1）
- 创建任务
- 删除任务
- 修改任务
- 对任务进行排序
- 切换任务状态
- 展示任务列表
- 已增加的任务会存储到用户设备上以供下次使用
### 本期不做（下一版本可能会支持）
- 支持移动端
- 任务存储在云端
- 支持多用户，用户可注册登陆
- 任务组，默认任务组
- 任务组可共享给其它用户，可进行查看、编辑
- 垃圾箱及找回任务功能
- 更多视图：看板视图、本周任务、本月任务、今日时间线任务
- 子任务、定期重复任务
- 备注、标签
- 统计功能
- 提醒通知
- AI自动分类、自动总结
 
## 功能需求
### 功能结构
- 查看待办
    - 可选中"显示已完成"复选框查看全部任务
    - 可进行搜索
- 新增/修改任务
    - 任务标题
    - 截止时间/日期
    - 任务优先级：高、中、低
- 可对任务列表进行拖动排序
- 可将任务切换为`已完成`或`未完成`状态
- 可删除任务
- 打开应用会展示已增加的任务
 
### 用户故事
- 作为用户，我希望能添加任务，以便记录待办事项
- 作为用户，我希望能将任务标记为完成
- 作为用户，我希望能将完成的任务标记为未完成
- 作为用户，我希望能在任务中携带优先级等信息，以便执行任务时获得辅助信息
- 作为用户，我希望能在对列表中的任务进行排序，以满足我优先执行哪些的需求
 
### 详细功能说明
#### 功能1：综述
- 用户打开应用后会加载并回显旧数据
- 应用主要包含筛选区域、列表区域
- 应用的每一步操作都会记录到本地
#### 功能2：列表与搜索
- 搜索区域内容
    - 单行文本输入框，placeholder提示为`任务标题`
    - `显示已完成`复选框，默认非选中，仅显示未完成任务，选中后显示全部任务
    - 输入文字即可搜索
    - 支持模糊搜索任务标题，不区分大小写
- 列表内容：
    - 按照任务的排序号由高到低列出所有任务
    - 待办任务的详情
        - 复选框：点击后在该条数据的状态在`已完成`和`未完成`之间切换
        - 任务标题（`已完成`状态颜色变灰，文字被划掉）
        - 优先级：在标题前显示叹号，高3个红色，中2个橙色，低1个蓝色，无数据则不显示
        - 截止日期时间（显示为相对时间，比如今天、明天、周五、6月7日；如包含具体时间则使用24小时制）
        - 截止日期时间早于当前时间时，日期显示为红色
    - 统计并显示出 未完成任务数量/任务总数量：n/sum
    - 当鼠标移动到某项任务时，显示出删除按钮
    - 当鼠标移动到某项任务且当前任务为`未完成`状态，显示编辑按钮
- 列表无数据的特殊状态
    - 无任何任务：请添加任务
    - 只有已完成任务且当前仅显示待办任务时：所有任务已完成
    - 搜索后：过滤后无任务
#### 功能3：新增任务
- 点击添加按钮弹窗显示出表单，可进行输入：
    - 任务标题文本输入框，必填，最长100字符
    - 任务优先级按钮组，选填，可选高中低
    - 截止日期时间，选填，使用可通用的日期时间组件，只能选择当前以后的日期
    - 点击保存会关闭弹窗，任务会被添加到列表中
- 后增加的任务会显示在列表最前
#### 功能4：编辑任务
- 与新增页面类似，新增时展示出的字段都可进行编辑，保存后更新数据
#### 功能5：切换状态
- 点击复选框选中，状态变为“已完成”
- 点击复选框取消选中，状态变为“未完成”
#### 功能6：删除任务
- 点击删除后会展示确认框：“确认删除任务：<任务标题>？”
- 确认删除为物理删除，不可恢复
#### 功能7：拖动排序
- 可使用鼠标拖动待办任务进行排序
- 当搜索的单行文本输入框有值时不可进行排序
- 在显示全部任务时所见即所得
- 当仅显示`未完成`状态待办时，将目标项目拖动到某任务前或后，结果在整个任务列表中会紧邻该任务。举例：
  - “abcde”五个任务，
  - 其中b和d为已完成任务
  - 当前仅显示`未完成`状态待办，ace
- 将e拖动到c之前，总体排序为abecd；将e拖动到c之后，总体排序为abced

### 任务对象字段

| 字段名         | 描述    | 是否必填 | 数据类型                 |
| ----------- | ----- | ---- | -------------------- |
| id          | uuid  | 是    | string               |
| title       | 任务标题  | 是    | string               |
| status      | 任务状态  | 是    | 可选 已完成done、未完成todo   |
| priority    | 任务优先级 | 否    | 可选 high、medium、low   |
| dueAt       | 截止日期时间，可精确到日期或时间 | 否    | 时间戳，可为空 |
| createdAt   | 创建日期  | 是    | 时间戳                   |
| updateAt    | 修改时间，编辑任务或切换状态时更新，更改排序不会更新该时间 | 否    | 时间戳 |
| completedAt | 完成时间，状态切换为已完成时写入，恢复未完成时清空 | 否    | 时间戳，可为空 |
| sortOrder   | 排序号，值越大越靠前 | 是    | 整数 |



## 用户流程
### 主流程
打开 App → 加载本地已保存任务 → 查看默认待办列表 → 执行新增/搜索/筛选/编辑/完成/排序/删除操作 → 每次操作后立即写入本地存储

### 新增任务流程
点击“添加任务”按钮 → 打开新增弹窗 → 输入标题、优先级、截止日期时间 → 点击保存 → 表单校验通过 → 新任务写入本地存储并插入列表最前 → 关闭弹窗并更新统计

### 编辑任务流程
鼠标移入未完成任务 → 点击编辑按钮 → 打开编辑弹窗并回显当前任务信息 → 修改标题、优先级或截止日期时间 → 点击保存 → 更新任务内容并写入本地存储 → 刷新列表展示

### 搜索与筛选流程
用户输入关键字 → 列表按标题模糊匹配实时过滤 → 用户切换`显示已完成`复选框 → 列表切换为“仅未完成”或“全部任务”视图 → 无匹配结果时展示对应空状态文案

### 切换完成状态流程
用户点击任务复选框 → 任务状态在`todo`和`done`之间切换 → 更新任务样式、统计数量、`completedAt`字段与本地存储 → 列表按当前筛选条件重新展示

### 删除任务流程
用户鼠标移入任务 → 点击删除按钮 → 显示确认框“确认删除任务：<任务标题>？” → 用户确认 → 任务被物理删除并写入本地存储 → 列表与统计信息同步更新

### 排序流程
用户拖动列表中的可见任务 → 将任务拖放到目标任务前或后 → 系统按规则更新整体任务顺序与`sortOrder` → 写入本地存储 → 列表按新顺序刷新

### 异常与空状态流程
- 首次打开且无任何任务时，列表显示“请添加任务”
- 当全部任务均已完成且当前仅显示未完成任务时，列表显示“所有任务已完成”
- 当搜索或筛选后无匹配任务时，列表显示“过滤后无任务”

## 验收标准
### 基础加载与持久化
- 用户首次打开应用且本地无任务数据时，页面正常展示空状态“请添加任务”，无报错
- 用户已有本地任务数据时，刷新页面后可完整恢复任务列表、排序、状态、优先级、截止日期时间
- 用户每次新增、编辑、切换状态、删除、排序后，最新结果都会立即写入本地存储

### 新增任务
- 点击“添加任务”后可打开新增弹窗，并展示标题、优先级、截止日期时间字段
- 标题为必填项；标题为空时不可保存，并给出明确提示
- 标题长度超过100字符时不可保存，并给出明确提示
- 截止日期时间若被选择，则只能选择当前时间及之后的时间
- 保存成功后，任务出现在列表最前，默认状态为`未完成`

### 编辑任务
- 仅未完成任务显示编辑按钮，已完成任务不显示编辑按钮
- 编辑弹窗需回显当前任务的标题、优先级、截止日期时间
- 编辑后保存成功，列表展示内容与本地存储数据同步更新
- 编辑任务时不修改`createdAt`，会更新`updateAt`

### 搜索与筛选
- 搜索按标题进行模糊匹配，且不区分大小写
- 搜索框输入内容后，列表实时展示过滤结果
- 默认仅显示未完成任务；勾选`显示已完成`后展示全部任务
- 搜索无结果时显示“过滤后无任务”
- 当仅显示未完成任务且所有任务都已完成时，显示“所有任务已完成”

### 切换完成状态
- 点击任务复选框后，可在`已完成`与`未完成`之间切换
- 任务切换为`已完成`后，标题变灰且加删除线
- 任务切换为`已完成`时写入`completedAt`；恢复为`未完成`时清空`completedAt`
- 切换状态后，未完成任务数量/任务总数量统计值立即更新

### 删除任务
- 鼠标移入任务项时显示删除按钮
- 点击删除按钮后显示确认框，文案包含任务标题
- 用户确认删除后，任务被物理删除且不可恢复
- 删除后列表、统计值、本地存储数据保持一致

### 排序
- 非搜索状态下，用户可通过拖动对任务进行排序
- 搜索框存在内容时，不允许拖动排序
- 显示全部任务时，拖动后的顺序与界面所见顺序一致
- 仅显示未完成任务时，拖动结果在完整任务列表中的位置需满足 PRD 示例规则
- 排序结果刷新页面后仍保持一致

### 列表展示
- 任务列表按`sortOrder`由高到低展示
- 优先级展示规则正确：高3个红色叹号，中2个橙色叹号，低1个蓝色叹号，无优先级则不展示
- 存在截止日期时间且已逾期时，日期显示为红色
- 统计区始终正确展示“未完成任务数量/任务总数量”

### 稳定性
- 连续新增、编辑、删除、切换状态、排序100次后，无页面报错且数据一致
- 在最新浏览器环境下，页面核心功能可正常使用，宽屏布局无明显错位或遮挡
